## 主要缺口

- 可直接训练的 TRAM-derived G1 motion target：暂无
- 官方 G1 样例数量不足：只有 1 条短 motion，只能验证训练框架，不能作为正式训练集
- AMASS-CMU / GenMimicBench 完整数据集未准备
- AMASS-CMU -> G1 的基础 retarget 链路具备雏形，但缺少真实数据下载、批量质量筛选、多 motion loader 与训练环境接入
- GenMimicBench 当前更适合后续视频端到端 benchmark；公开数据是视频，不是可直接训练的 G1 target
- G1 轨迹严格地面对齐版本已清除穿地，但 root orientation 大范围翻转，视觉表现为悬空旋转
- Isaac Lab 长视频 headless 录制不稳定；且当前轨迹质量不适合录制展示视频
- 正式 Teacher PPO 尚未完成：当前已有可复用 env 与训练入口，但 reward / motion sampling / eval 仍是最小版本
- Symmetry Loss / Student DAgger 仍未进入开发
- 官方 GenMimic 代码与数据暂未完整开源
- 自有视频泛化验证暂时跳过
